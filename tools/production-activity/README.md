# Активность Производства

Счётчик обращений пользователя к Codex/Claude Code. Это приближённая нагрузка, не завершённые задачи.

Коллектор читает `.codex/sessions`, `.codex/archived_sessions` либо `.claude/projects`. Системные события, результаты инструментов и подагенты исключаются. Глобальные идентификаторы/хеши сообщений предотвращают дубли при повторном чтении. Локальная SQLite хранит только хеши и время. На сервер уходят почасовые суммы за 180 дней. Текст сообщений, названия проектов и пути не передаются.

Облачные сессии без локального журнала не видны. Период до первого доступного обращения отмечается как неполный, отсутствующий источник не заменяется нулями. Общая линия суммирует доступные источники. Просмотр доступен супер-администратору.

## Установка macOS

В частном пакете должны быть `collector.py`, `install.command`, `config.json`. Конфигурация содержит отдельный ключ только для отправки счётчиков одного источника. Никогда не коммитить конфигурацию или архив с ней. Нужен Python 3. Запустить `install.command`. Устанавливается LaunchAgent с интервалом 600 секунд. Компьютер должен быть включён и иметь интернет.

Удаление: `launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/kz.pllato.activity.claude.plist`, затем удалить этот plist. Для Codex заменить `claude` на `codex`. Для отзыва ключа удалить или заменить соответствующий SHA-256 в worker/production-sources.json и опубликовать Worker. Там хранятся только хеши, не ключи.

Тесты: `python3 tools/production-activity/test_collector.py`; `node tests/production-activity.mjs`.
