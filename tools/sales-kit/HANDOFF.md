# Демо + КП + Договор + Счёт — инструкция для нового агента

Работа: после встречи с клиентом (транскрипт `.vtt` от Платона) собрать кликабельное демо, КП со скриншотами,
при необходимости договор с ТЗ и счёт на предоплату; выложить на pllato.kz и добавить карточку в `app.html`.

## 1. Подключение

- Репозиторий `pllato/pllato.kz`, рабочая ветка — та, что выдана сессии (была `claude/pllato-app-edits-wnoai9`).
- Прочитать `AGENTS.md` (правила дизайна, запреты) — и этот файл.
- Запустить локальный сервер (порт 8199, корень репозитория):

```bash
cd /home/user/pllato.kz && (nohup python3 tools/sales-kit/scripts/serve.py >/tmp/serve.log 2>&1 &)
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8199/app.html   # 200
```

Сервер иногда падает — при `ERR_CONNECTION_REFUSED` запустить снова. Chromium и Playwright в среде
предустановлены, скрипты находят их сами. Ключ к гейту `/app/gate.js` скрипты вычисляют сами — в репозиторий его не класть.
Google Fonts в песочнице не грузятся: скриншоты и PDF выходят с запасными шрифтами, это нормально.

## 2. Скрипты (`tools/sales-kit/scripts/`)

| Скрипт | Что делает |
|---|---|
| `serve.py` | локальный сервер |
| `demo-test.js <демо> "<роль>" "<действия;>"` | все экраны, кнопки, роли, сценарий ▶. Нужно `BAD: 0` |
| `demo-clicks.js <демо>` | ищет, какая кнопка даёт ошибку JS |
| `demo-mobile.js <демо> [экраны] [папка]` | телефон 390px: вход по роли, нет горизонтальной прокрутки |
| `demo-look.js <демо> gate,экран <папка>` | PNG экранов, чтобы посмотреть глазами |
| `demo-shots.js <демо> <папка> "<полные>" "<обрезки>" '<модалки>' cx cy "<js>"` | JPG для КП в `app/img/<папка>/` |
| `kp-build.py <проект>/kpcfg.py` | собирает КП `app/kp-*.html` |
| `contract-pack.js <html> <body_packed.html>` | плотно раскладывает договор по листам |
| `page-check.js app/<док>.html` | листы A4 не выше 1123px, нет битых картинок. Нужно `BAD: 0` |
| `pages-png.js app/<док>.html <префикс>` | PNG каждого листа для проверки глазами |
| `pdf.js app/<док>.html app/<док>.pdf` | PDF A4 |
| `live-check.sh <файлы…>` | ждёт, пока файлы появятся на pllato.kz (сверка md5) |

Демо-аргумент — имя файла без `.html` (`kvarta-sanzhar`). Пути документов — от корня репозитория.

## 3. Демо

Каркас — `app/uss.html` (вёрстка) + JS проекта. Исходники пяти последних демо лежат в `tools/sales-kit/projects/`
(`apteka-flow-yerlan`, `kamerton-akmaral`, `kvarta-sanzhar`, `rashit-pack`, `eventflow-inna`) — новый проект
начинать с копии самой близкой папки.

- `build.py` берёт `app/uss.html`, меняет title, favicon, шрифты, палитру `:root` и `body.dark`, экран входа (гейт),
  логотип, поиск, кнопку «+», при необходимости собственный каркас приложения; добавляет `style.css`;
  склеивает `p1.js…p7.js` в `app/<имя>.js` и пишет `app/<имя>.html`.
- Внутри JS: `SEC` (разделы меню), `ROLES` (роли и их экраны), данные, `SC.<экран>` (экраны), `CARD.<тип>` +
  `card()` (модалки), `act()` (действия-заглушки), `said()` (цитата клиента «Вы сказали на встрече»),
  `TOUR` (сценарий ▶), `?s=<экран>` (открыть сразу экран).
- Гейт: логотип, заголовок в три строки, боль клиента его словами, что делает система, 4 цифры
  (экранов / ролей / …/ цена), справа список ролей.
- Все имена, суммы, номера — вымышленные. Цитаты — из транскрипта.
- `<script src="/app/gate.js"></script>` — первым тегом в `<head>` (в `uss.html` уже есть).
- **Не менять `app/uss.html`** — это и каркас, и живое демо клиента.

Грабли:
- В инлайн-`onclick` не использовать переменную `role` — там это ARIA-свойство элемента. Выносить в функцию.
- Имена классов не должны совпадать с базовыми (`.res`, `.tr`, `.st` и т. п.) — иначе ломается вёрстка.
- `<b>` внутри некоторых блоков (`.mod`, группы) — блочный; для жирного в тексте брать `<strong>`.

Проверка: `demo-test` → `BAD: 0`, `demo-mobile` → `BAD: 0`, глазами — `demo-look`.

## 4. КП

- Папка проекта: `kp_pages.html` (листы `<section class="page">`) + `kpcfg.py` (палитра, шрифты, логотип).
  Стили берутся из `app/kp-bobek.html` — **его не менять**.
- Обычный порядок листов: обложка → «Ваши слова на встрече → что сделано в демо» → 8–10 листов «экран + что даёт»
  со скриншотами → интеграции/запуск → стоимость и этапы оплаты.
- Скриншоты: `demo-shots.js` в `app/img/kp-<имя>/`.
- Сборка и проверка:

```bash
python3 tools/sales-kit/scripts/kp-build.py tools/sales-kit/projects/<проект>/kpcfg.py
node tools/sales-kit/scripts/page-check.js app/kp-<имя>.html          # BAD: 0
node tools/sales-kit/scripts/pdf.js app/kp-<имя>.html app/Pllato_KP_<Имя>.pdf
```

## 5. Договор с ТЗ

- Образцы: `tools/sales-kit/projects/dogovor-bipharm/` и `dogovor-kfpu/`. Стили берутся из `app/dogovor-saldo.html`.
- `body.html`: разделы 1–12 (предмет, стоимость и расчёты, сроки и этапы, приёмка, права, обязанности,
  сопровождение, конфиденциальность, изменение объёма, ответственность, прочее, реквизиты и подписи)
  → Приложение 1 «Техническое задание» (разделы Р1…, повторяют экраны демо) → Приложение 2 «График платежей и форма акта».
  `{P}` — номер страницы, `RUNFOOT` — подвал, `LOGO` — логотип.
- Сборка:

```bash
P=tools/sales-kit/projects/dogovor-<имя>
python3 $P/build.py                                                     # по разделам
node tools/sales-kit/scripts/contract-pack.js app/dogovor-<имя>.html $P/body_packed.html
python3 $P/build.py body_packed.html                                    # плотно
node tools/sales-kit/scripts/page-check.js app/dogovor-<имя>.html       # BAD: 0
node tools/sales-kit/scripts/pdf.js app/dogovor-<имя>.html app/dogovor-<имя>.pdf
```

Типовые условия: 10/45/45 (предоплата → приёмка ядра → после шлифовки); ядро за 2 недели, всё за 4–6 недель;
шлифовка с участием клиента, резерв ~15% на доработки; сопровождение 3 месяца, дальше 20 $/час;
интеграции — только при наличии API у стороннего сервиса (иначе файлы или ручной ввод, без изменения цены);
сервер, WhatsApp-провайдер, ОФД, ЭЦП оплачивает клиент; права — после полной оплаты; подписание ЭЦП.

## 7. Карточка в `app.html`

Новая карточка — `<div class="tool-card" data-app-id="…" data-created="ГГГГ-ММ-ДД" data-updated="…">` выше
предыдущих: иконка, `<h3>`, `<p>` с сутью встречи и цифрами, кнопка «Открыть демо →», в «Материалах проекта»
ссылки на экраны (`?s=`), КП, PDF (`class="is-pdf"`), договор и счёт. Плюс строка в `APPS_CATALOG`
(`{ id: "…", label: "…" }`). Образец — карточка `yerlan_pharmacy_flow`.
