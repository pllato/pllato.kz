# Pllato Activity — расширение для команды

Chrome / Edge на Windows и macOS. Пароли, Python и терминал сотруднику не нужны.

## Установка

1. Распакуйте личный командный архив **Pllato-Activity.zip** в постоянную папку. Не удаляйте папку после установки.
2. В Chrome откройте `chrome://extensions`, в Edge — `edge://extensions`.
3. Включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите папку **extension**, внутри которой находится manifest.json.
4. Откроется Pllato Activity. Введите имя и фамилию, нажмите «Подключить учёт». Если окно не открылось: значок пазла → Pllato Activity.
5. Обновите уже открытые вкладки Claude и Codex. Расширение работает только в том профиле браузера, куда установлено.

В popup видны локальные счётчики, последнее успешное обновление каждого сервиса, ошибки и кнопка паузы. Новые данные отправляются каждые 10 минут при работающем браузере; «Обновить сейчас» отправляет сразу. Пауза останавливает сбор и отправку, возобновление не восстанавливает пропущенные обращения. Удаление расширения удаляет локальные настройки; серверная история остаётся.

## Что учитывается

Новые отправки на claude.ai и chatgpt.com/codex после подключения. Совпадают два признака: действие отправки пользователя и HTTP 2xx от разрешённого endpoint отправки. Поток ответа не читается: это счётчик принятых отправок, не успешно выполненных задач. История, ответы ИИ, обычные чаты ChatGPT, GET-запросы, фоновые обращения, инкогнито и настольные приложения не учитываются.

Адаптер v1: Claude `/api/organizations/*/chat_conversations/*/completion`; Codex `/backend-api/{wham,codex}/tasks` и `/tasks/*/{turns,messages}`. Новые/изменённые endpoints не засчитываются автоматически. После обновлений сайтов администратору нужно проверить одну реальную отправку на каждом сервисе; неизвестные маршруты не включаются по догадке.

Тексты запросов/ответов, файлы, код, cookies и заголовки авторизации сайтов не читаются и не передаются. На сервер передаются имя, идентификатор установки, служебный ключ этой установки, время синхронизации и почасовые счётчики. Имя указывается самим сотрудником и не является подтверждённой личностью. Укажите одинаковое имя на своих рабочих компьютерах; совпавшие имена объединятся на графике. Для однофамильцев добавьте отличительный суффикс.

Повторная отправка снимка не увеличивает сумму. Локально хранятся последние 180 дней. Одинаковая сессия, одновременно учтённая локальным сборщиком и браузером, может попасть в сумму дважды — используйте один источник для одной сессии.

## Сборка для администратора

`python3 tools/browser-activity/package.py --output /absolute/private/Pllato-Activity --sources crm/worker/production-sources.json`

Скрипт создаёт отдельный ключ регистрации с ограничением 30 дней, копирует его только в приватный установочный пакет, а в серверный реестр пишет SHA-256. Сначала опубликуйте реестр на pllato-comm. После окончания срока уже установленные устройства продолжают работать. Для новой партии используйте другую выходную папку/ключ. Повторный запуск для той же папки сохраняет ключ и дату окончания.

Архив можно передавать только своей команде: ключ в нём позволяет регистрацию новых отправителей счётчиков, но не чтение CRM или переписок. Не выкладывайте архив на публичный сайт/GitHub. Отозвать регистрацию новых установок: удалить соответствующий enrollment из реестра и опубликовать Worker. Ключи устройств независимы, общий ключ регистрации не используется при отправке статистики.

Проверки: `node tests/browser-activity.mjs`, `node tests/activity-people.mjs`, `node tests/production-activity.mjs`, `node tests/activity-multi.mjs`. Регистрация проверяется `tests/activity-browser-registration.mjs` в core repo.
