# Доставка материалов Pllato Meet

CRM-встречи: один id на отдельную сессию постоянной комнаты. `/archive/session/crm/:id` создаёт два файла со статусом processing. Все записи разрешены только с приватным ключом комнаты; чтение остаётся через доступ к сделке CRM.

Организатор сохраняет видео и моно PCM 16 kHz в IndexedDB. AudioWorklet выдаёт независимые WAV по 60 секунд и последнюю неполную часть при остановке. Звук загружается в R2 с ключом (session, sequence), затем создаётся уникальная задача D1. Последние части и metadata должны быть подтверждены до удаления локальной копии. При повторном открытии архива незавершённые копии отправляются повторно.

Минутный cron выбирает до 8 задач; lease 5 минут, максимум 6 попыток с задержками. Cloudflare-hosted Whisper large v3 turbo не запускается на телефоне. Публикация TXT происходит только при совпадении ожидаемого числа частей и их последовательности. Пустое распознавание означает «речь не обнаружена», а не выдуманный текст. Имена говорящих из смешанного звука не определяются.

Сбой браузера до отправки последнего фрагмента нельзя исправить сервером без исходного устройства. Через 5 минут без новых частей незавершённая сессия обозначается interrupted. После финализации отсутствие частей больше суток или исчерпание попыток обозначается failed. Записи и исходный звук при этом сохраняются.

Развёртывание: применить `meet-worker/migrations/0001-delivery.sql` в CRM D1, затем deploy meet-worker с AI binding и cron. ELC Worker и Pages через обычный PR. Результаты и ошибки проверяются в meet_delivery, meet_audio_jobs и zoom_files, без публикации host_key.
