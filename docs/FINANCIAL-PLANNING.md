# Финансовое планирование

App → «7 Отделение — Админ» → «Финансовое планирование».

Владелец настраивает точный список сотрудников в настройках плашки. По умолчанию доступ только у владельца. Роли: просмотр и редактирование. Обычный статус администратора или супер-администратора не даёт доступа. API каждый раз проверяет список; общая синхронизация Store не читает и не записывает эту коллекцию.

Таблица на 52 недели: 8 прошлых, текущая и 43 будущих при первом сохранении. Недели с четверга 14:00 до четверга 14:00 Алматы. Названия статей закреплены слева; текущая неделя подсвечена, стрелки и выбор недели работают на телефоне и компьютере. «Образец B» возвращает к показательному столбцу. Изменения сохраняются кнопкой «Сохранить». «Обновить» заново получает доход и выплаты из проектов.

Доход — тот же расчёт, что общий недельный график кассы, включая курс USD и исторические корректировки. Выплаты берутся из реестра каждого проекта, отдельно оплаченные и плановые. Нажатие на сумму открывает состав выплат; статьи по ролям получателей добавляются автоматически. Выплата без времени относится к 00:00 её даты, поэтому четверг относится к заканчивающейся неделе.

Ручные статьи: расход, доход, налог или расчётная строка. Налог вводится ставкой (например 3 означает 3%). Ставка из B применяется ко всем неделям, пока для отдельной недели не задана своя. Недельная ячейка показывает рассчитанную сумму налога в ₸.

Формулы: арифметика, скобки, проценты, SUM. `=R1*3%` — доля дохода текущего столбца; `=C1-C2` — конкретные ячейки; `=SUM(R4:R5)` — диапазон в одном столбце. R зарезервирована для текущего столбца. Формулы не исполняют JavaScript; циклы и деление на ноль показывают ошибку.

Чистая прибыль = касса + ручной доход − оплаченные выплаты − ручные расходы − налоги. Остаток после плановых выплат дополнительно вычитает запланированные выплаты. Расчётные и детальные строки выплат не вычитаются повторно. Под каждой суммой показывается её процент от дохода кассы.

Сервер хранит ревизию таблицы и отклоняет конфликтующие сохранения (409), не перезаписывая чужие изменения.
