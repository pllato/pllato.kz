## 0.17.75 — нулевая ширина создаваемого TEXT

Пользователь выполнил AUDIT / No в настоящем AutoCAD: 44 ошибки, 0 исправлено.
Это 22 TEXT, повторённые в двух проходах. Локальная проверка тех же handles
подтвердила width_factor=0. Конструктор dwg_add_TEXT в библиотеке теперь задаёт 1;
это распространяется на оформление и текст геометрии размеров. Полностью
пересобраны host/WASM library, writer и corresponding GPL source archive.
pllato_save отклоняет nonfinite/nonpositive TEXT width до записи, не исправляя
молча импортированные тексты. Обычный writer показывает причину отказа.

Проверены 192 unit tests, native executive regression, отдельная регрессия
TEXT: новая ширина 1, отказ для 0/-1/NaN и round-trip ширины 0.75.
Новый browser worker test dwg-text-width-worker.cjs проходит создание, отдельный
экспорт, повторный экспорт, добавление TEXT обычным writer и повторное сохранение.
Старый dwg-executive-export-browser.cjs не проходит текущий UI (скрытые controls,
после локальной адаптации — timeout ожидания листа); не выдавать его за passed.
Section-framing regression проходит прямой writer output; его поиск несжатых
sentinels не пригоден для ODA-перезаписи (на ней тест завершается ошибкой).
В частной копии исправлены ровно 22 найденных TEXT, сохранены 9958 записей;
отдельная ODA-конверсия без Audit/Recover прочитана обратно, все ширины равны 1.
Исходники не изменялись. Эта локальная копия НЕ является прямым браузерным
экспортом: использовалась ODA-перезапись. Новый AUDIT пользователя ещё нужен.
Не считать исправленными исходный AutoCAD invalid-DWG, подстановку отсутствующих
шрифтов, общий wrapper плана или совместимость всех версий. Прямого доступа
к AutoCAD инструментами агента нет; не заявлять независимую приёмку.

## 0.17.73 — диагностика версии DWG

AC1021 (2007–2009) ранее читался, но pllato_save сразу возвращал 2048 из-за
отсутствующей безопасной записи R2007. Теперь при открытии показано постоянное
предупреждение; оба writer worker отклоняют этот формат до тяжёлой работы с
инструкцией подготовить отдельную CAD-копию DWG 2018. SAVE_REJECT из executive
writer включён в сообщение ошибки. Проверки native не ослаблены.
Это НЕ автоматический конвертер и НЕ поддержка всех версий. Для browser-only
автоматической конверсии необходим отдельный CAD conversion backend/SDK.
Частный 2435 DWG локально преобразован ODA в отдельный AC1032 без Audit/Recover;
неизменённая преобразованная копия проходит pllato_save/readback (код 4).
Последующая browser-проверка: AC1032-копия падает в reader с memory access out of
bounds. AC1027 (ODA 2013) открывается, но создание выбранного плана отклоняется
CLONE_REJECT_TYPE PROXY_OBJECT (код 11), даже без рамки/штампа. Конверсия сама по
себе НЕ устранила проблему пользователя. Нужна поддержка proxy-графа/другой CAD
backend; обход этих проверок недопустим. 192 unit tests. Частные файлы и их
содержимое в Git не включены.

## 0.17.64 — независимая проверка DWG / исправление CRC

Причина отказа приложенной исполнительной установлена через локальный официальный
ODA File Converter 27.9: `CRC does not match`. В encode.c Header/Classes для
расширенного 64-битного префикса длины ошибочно включали старший DWORD в длину
полезных данных. Classes также записывал bitsize/8 вместо нулевого старшего DWORD.
Исправлены оба значения; CRC по-прежнему охватывает оба DWORD и данные. JS/WASM
пересобраны, соответствующий GPL-архив обновлён. Никакие CAD-проверки не отключены.

Проверено: 186 unit tests; native clone/attributes/rotation/ownership regression;
исполнительная пользователя (16064 объекта) save/read/save; отдельный браузерный
сценарий 7 точек, спуски, undo/redo, clipboard, сохранение/открытие. ODA без AUDIT
и RECOVER успешно прочитал и записал как исправленную исполнительную, так и файл
после браузерных правок. `tests/dwg-section-size-regression.mjs FILE` проверяет
реальное положение CRC/конечных sentinel в несжатых Header/Classes DWG2018.
Customer probe поддерживает DWG_OUTPUT_FILE (только новый локальный файл, wx).

Ограничение: полный исходник пользователя (168486 объектов), хотя проходит прежний
same-engine gate с предупреждениями 68, отвергается ODA на multiline ATTDEF C7EEE2:
`Object improperly read`. Исходный файл ODA читает нормально. Это отдельная ошибка
сериализации/декодирования атрибута, не исправленная этим релизом. Не заявлять
универсальную совместимость всех исходников или проверку на физическом планшете.
AutoCAD не требовался; частные DWG никуда не отправлялись и не коммитились.

## 0.17.62 — подтверждаемый перенос связанного размера

При переносе DIMENSION с DIMASSOC спрашиваем подтверждение отключения привязки.
Отказ не меняет документ. Согласие записывает detachDimension вместе с переносом
в одну undo/recovery-операцию; число, стиль и private cache сохраняются.

reactors, обнуляет associativity и неактивные snap references. Raw DIMASSOC
переводится в typed только после существующей побитовой проверки coverage.
Неизвестный хвост и внешние xref paths отклоняются. Защита общего кэша и
проверки записи/повторного чтения остаются. WASM и GPL archive обновлены вместе.

Проверено на частном исходном DWG пользователя: native detach/move/save/read,
браузерный перенос размера 950 с подтверждением, undo/redo и download/reopen.
Независимой проверки в AutoCAD нет. Привязка отключается намеренно, поэтому
такой размер больше не следует за исходным объектом средствами AutoCAD.

## Что пользователь строит

Рабочий процесс: открыть большой DWG → выбрать план → создать независимую исполнительную
на свободном месте → повернуть/оформить → править приборы и кабели → назначить марку и
сечение → поставить нужные выноски → получить ведомость длин слева снизу → сохранить
всё редактируемым в новой DWG-копии. Нужны автосохранение, история и отсутствие потерь при сбоях.

Особенно важны: выделение всей трассы вместе с поворотами, сохранение исходной CAD-структуры,
длина при рисовании/выборе, рисование по трём точкам как в графическом редакторе,
перемещение/удаление/копирование приборов и кабелей, цвет кабеля, редактируемые подписи.
Назначенный кабель должен учитываться и без выноски.

### Модель данных: не путать уровни

Исходные байты + `doc.nativeOps` + новые примитивы + executive project передаются writer-у.
Экранная сцена не является источником для полного пересоздания DWG.

- `dwg-HANDLE` идентифицирует исходную запись. `shape.entityId` — геометрическая запись,
  `shape.id` — корень; `deviceId` — экземпляр прибора; `entityKey` учитывает корень и матрицу.
  Выбранный штрих и содержащий его INSERT — не одно и то же.
- `selectedChain` содержит ключи для подсветки и отдельные ключи/пути измерения без повторов.
  Подрезка нахлёстов используется для длины, исходные CAD-объекты не обрезаются.
- Executive project version 1: sheets, `nativeHandles`, origin, planCentre, paperUnit,
  metresPerUnit, angle, stamp, routes. Трасса содержит points, brand, section, extraMetres,
  leaders; исходная назначенная трасса дополнительно `sourceIds`/paths; новая — controls/smooth/color.
- Удаление исходного назначенного кабеля должно удалить его запись из ведомости.
  Снятие назначения и удаление геометрии — разные действия.
- Ведомость строится из назначенных трасс, а не распознаётся автоматически из всех текстов DWG.
- Длины требуют правильных единиц/калибровки. Кривые измеряются приближённо; добавочная длина неотрицательна.
- История: IndexedDB `pllato_dwg_recovery`, sources/revisions. Она локальна устройству/браузеру,
  не является облачной резервной копией и не заменяет скачивание DWG.

## Оставшиеся ограничения / следующие проверки

- Независимый AutoCAD round-trip: геометрия, атрибуты, цвета, ведомость, размеры и принадлежность объектов.
- Повторить пользовательские кабельные случаи на его текущем файле в режиме целой трассы;
  при остановке исследовать точные типы/handles/концы/слой/цвет/матрицу. Не увеличивать допуск вслепую.
- Реальные ветвления/зазоры требуют выбора пользователем, а не угадывания всей сети.
- Proxy/dynamic/сложные зависимости и некоторые операции с reactors/extension dictionaries
  могут быть отклонены. Предпросмотр не доказывает успешный native export.
- Только 2D model space. Отсутствующие оригинальные CAD-шрифты заменяются свободными;
  точного совпадения со всеми GOST/isocpeur/SHX нет.
- Новые кривые и подтверждённая правка формы исходных кабелей — аппроксимация.
- Проверить присвоение марок скопированным исходным кабелям: копирование геометрии само по себе
  не означает автоматическое назначение всех копий в ведомость.
- Дальнейшее нагрузочное тестирование больших документов, отмены, восстановления после crash,

# 0.17.46 — добавление пропущенных участков в выделение

«Добавить / убрать участок» теперь принимает явно указанные LINE/ARC/полилинии/SPLINE,
не входившие в первоначальную цепочку. Повторный клик исключает участок; Shift + клик
делает то же без включения режима. Доступно и при выборе одного участка.
Hit-test использует spatial index; скрытые слои, текст, заливки и другие экземпляры
блоков не подмешиваются. Автоматическое соединение ветвлений не изменено.
Это изменение выделения, а не геометрии; дальнейшие операции используют существующие
проверки CAD и undo/recovery. Проверено: 140 unit tests и refine browser regression
(исключение, возврат, добавление ранее отсутствовавшего участка, длина, перенос,
удаление только выбранных частей и undo). Независимой проверки AutoCAD нет.
# 0.17.47 — маркер поворота прибора

Удалена toolbar-кнопка cwRotate. На выбранном поддерживаемом INSERT появляется
голубая точка «Поворот» над прибором, соединённая с точкой вставки. Перетаскивание
показывает контур, отпускание записывает один поворот через прежний native angle op;
Escape отменяет незавершённый жест. Во время движения DWG не перечитывается.
rotation-handle.mjs учитывает матрицу родителя (поворот, масштаб, отражение).
Ограничения прежние: один INSERT без ATTRIB; не добавлена ротация произвольных линий.
Проверено: 141 unit tests; rotation browser на отдельном синтетическом nested INSERT:
drag, undo/redo, DWG save/reopen. tests/dwg-rotation-fixture.c собирается как clone fixture.
Независимой проверки в AutoCAD нет.
