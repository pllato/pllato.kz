## Дополнительные ошибки

- Вернулись точные ручки LINE и LWPOLYLINE, без замены исходной кривой.
  SPLINE с управляющими точками сохраняет прежнюю поддержку. Для произвольных
  ARC/fit-point spline универсальные ручки не добавлены.
- Краш создания исполнительной на большом файле не воспроизведён и не считается
  исправленным. Нельзя обещать отсутствие переполнения памяти.
- ROOT_REJECT type=LINE mode=0 воспроизводится и на исходном файле: native-reader
  видит неправильный тип владельца для части объектов. Только часть таких
  объектов имеет однозначную принадлежность к списку блока. Автоматическое
  угадывание владельцев или отключение защиты может потерять геометрию.
  Дополнительно остаётся ограничение MTEXT с extension dictionary.

## Проверки

- Unit: геометрия, история, таблица, заголовок, инкрементальный индекс.
- Native write/read: точка LINE, центрирование TEXT, LAYER off без удаления слоя.
- Browser workbench: четыре точки, узлы, перемещение, выноска, копия, отмена без
  повторного DWG-reader, навигатор, заголовок, Excel-таблица, DWG roundtrip.
- Локальная перерисовка сравнивается попиксельно с полной на пересекающихся линиях.
- PDF проверяется Poppler: A3, встроенный osifont/Unicode, без растровой подложки.
- Проверки независимым AutoCAD не выполнены.

## Скорость большого файла

На локальном файле ~43 МБ, 964317 примитивов, отдельный headless Chrome:
открытие около 19–20 с. В ходе этой разработки удаление одной выбранной корневой
LINE на общем виде сократилось с 1485–1524 мс до 200–283 мс (финальные 3 повтора).
Отмена заняла 99–117 мс и не запускала reader. Это ограниченный сценарий, не обещание 2× для всего
редактора или любого ноутбука. Следующие приоритеты: native чтение/передача,
большие исполнительные, повторная полная отрисовка после изменения оформления.
